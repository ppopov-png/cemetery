# Dataset licensing policy

The collector accepts only records with an explicit machine-readable license or public-domain declaration.

Default allowed policy:

- CC0 / Public Domain;
- CC BY;
- CC BY-SA.

Creative Commons licenses with NC or ND restrictions, unknown licenses, missing license URLs, and ambiguous rights are rejected by default. This policy is intentionally conservative and can be changed only in code/config with a recorded policy version.

Each accepted image keeps its own license metadata. Wikimedia Commons is not treated as one-license source: every file is evaluated independently. Open Images image licenses must be independently verified by the dataset operator; the official Open Images metadata warning is preserved in the record. Flickr Commons is optional and accepts only explicit API license values allowed by policy.

The repository contains collector code and documentation only. Downloaded images, generated reports, and dataset manifests are not committed.
